# Tag Questions + Sound — گرامەری پۆلی ١٢

ماڵپەڕێکی فێرکاری بە سۆرانی بۆ پۆلی ١٢:
- **Tag Questions**: یاسا، یاسا تایبەتەکان، ١١٥ پرسیار، هەڵە باوەکان، لیستی خێرا
- **Sound (دەنگەکان)**: ٤٤ دەنگی ئینگلیزی، پیتە ناخوێنراوەکان، پاشگرەکان (-ed / -s)، بزوێن و جووت بزوێن، پاڵپەستۆ، ١٤١ پرسیاری دەنگ
- **خوێنەرەوە**: هەر وشەیەک بنووسیت یان کلیکی لەسەر بکەیت، بە ئینگلیزی بریتانی (en-GB) دەخوێنرێتەوە

A Sorani Kurdish study site for Grade 12 English: tag questions and the full Sunrise 12 sound unit,
with click-to-listen British pronunciation (Web Speech API), a word reader, and quizzes.

## Features
- Tabs: every top tab opens its own page
- No dependencies: a single `index.html` (Speda font and photo embedded)
- Works offline; mobile- and print-friendly
- Voice: choose an `English (United Kingdom)` voice in the voice bar (installed on the device)

## Publish on GitHub Pages
1. Upload all files in this folder to a new repository.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
3. Your site will be at `https://USERNAME.github.io/REPO/`.
